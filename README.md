# [proyecto Flask]
[“Aplicación
web básica hecha con Flask que muestra una página de inicio y una página ‘Acerca de’. Es el proyecto base de la actividad clave 1.”]
## Requisitos
- Python 3.12 o superior
- Git
## Instalación
1. Clona este repositorio: `git clone [https://github.com/fmaya0256-art/pr3va-ac1-entorno-flask..git]`
2. Entra a la carpeta del proyecto: `cd [fernando-proyecto-flask]`
3. Crea el entorno virtual: `python -m venv .venv`
4. Actívalo: en Windows `.venv\Scripts\activate`; en macOS/Linux `source
.venv/bin/activate`
5. Instala las dependencias: `pip install -r requirements.txt`
6. Crea tu archivo de configuración a partir del ejemplo: en Windows
`copy .env.example .env`; en macOS/Linux `cp .env.example .env`
## Ejecución
`python app.py`
Abre tu navegador en http://127.0.0.1:5000
